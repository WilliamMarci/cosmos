# Calendar

The first bundled UI package Mod. Click the status bar date/time to toggle a compact current-month calendar immediately above it. Today is highlighted using the current Cosmos palette.

Left / `,` and Right / `.` move one month, Home returns to this month, Escape / q closes, `?` opens shared shortcut help. These keys are editable under Settings → Keybindings → Mods.

Settings → Mods → Calendar controls Enabled and Notification permission separately. Notification permission defaults Off; this display-only Mod does not send reminders. All calendar code and its manifest live in this folder; move/copy it intact and register its directory through ui_mod_paths as documented in docs/ui-mods.md. No host file imports this package by name.
