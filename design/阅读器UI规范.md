# 阅读器 UI 约定

2026-10-23 用户修订。沿用《可扩展终端工作壳：最终设计规范》的克制原则与《UI分区与Agent接入》的应用级空间边界；本约定覆盖先前将阅读选项平铺、套用 Powerline 的实现。

阅读界面以正文为主，不把工具按钮当作主体。阅读器的底栏属于源窗格，不借用 Cosmos 全局状态栏。

## 底栏

- 左对齐：文件名、当前章节。名称太长时分别分配空间，不能把章节完全挤掉。
- 右对齐：阅读进度（百分比、当前页/总页）。最右端固定一个大纲开关，折叠后仍可恢复。
- 阅读选项只保留一个小入口 `≡`，位于进度左侧，不平铺分栏/滚动等全部选项。
- 使用主题角色、普通方形底色和单色 Unicode/简短文字。不写方括号按钮，不画 Powerline、胶囊或箭头接头。
- 大纲顶部只显示标题，不再放第二个折叠按钮。

## 阅读选项菜单

点击入口后在其上方向上展开，宽度不超过 27 格；每个选项严格一行，置于阅读窗格内，不改 PTY 尺寸。

- `Col       ◂ Auto ▸`：自动/1/2/3 栏。
- `Scroll  ◂ Enable ▸`：滚动开关。
- `Ln space     ◂ 1 ▸`：文字行距 1/2/3；不拆散图片与表格。
- `Image size ◂ 8 ln ▸`：内嵌插图高度上限。

左右三角可点击循环，键盘上下/Tab 选择行，左右调整；Esc/q 只收起菜单。打开状态属于当前客户端，不能让其他客户端一起弹出。

## 插图与表格

基础方形色块按钮、无装饰符，hover 立即改变当前按钮，不渐变。复制按钮用 `⎘`；展开、折叠用简短单色 Unicode。小图标按原始尺寸显示且没有按钮。放大图片继续复用现有图片 Reader。

所有覆盖内容与底色统一参与现有字符/图形批次；图片画布不得遮掉按钮底色。菜单只覆盖自身矩形，不能清空整个阅读区域。
