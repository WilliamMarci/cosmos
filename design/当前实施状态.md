# Cosmos 当前实施状态

更新日期：2026-10-23。本页描述当前代码状态；历史过程见《实施进度》，目标范围见《实施方案-v0.1》和《UI分区与Agent接入》。不把接口声明、示例或启动外部程序等同于完整功能交付。

## 当前定位

当前标记为 **Arche · 0.1.0，首个开发版**。基础框架与终端工作区已经可运行，正在完成各业务模块接入；开发版不等于设计中的完整首版。没有统一工时估算或验收权重，暂不报告容易误导的完成百分比。

当前唯一 UI 入口为根目录 `./cosmos`，使用 Python + Textual 宿主和 Cosmos 自绘接口，终端会话与 VT 解析依赖隔离的 Tmux 服务。Rust 暂留协调服务与管理 CLI；直接运行 `target/release/cosmos` 及 attach/workspace 均转到 Python UI。旧 Rust UI 停用，源码只留历史参考。冻结边界见《入口与框架冻结记录》。

## 已有运行验收

- **基础服务**：本机 IPC、版本协商、配置持久化、事件订阅与回放、通知服务；可信外部 Mod 的注册、启动、停止、就绪握手与进程管理。能力声明不构成系统沙箱。
- **终端工作区**：持续会话与重连，窗口/窗格创建和切换，分屏、缩放与调整大小，鼠标点击焦点；应用启用鼠标跟踪时可透传点击、拖动与滚轮；Tmux 几何分割线、交点和双窗格局部焦点高亮；精简当前窗口状态栏。
- **交互基础**：Leader 设置入口、Ctrl+P 上下文 Actions、可点击 cosmos 开始菜单及 Mod 分组注册，上下文帮助与独立设置 Panel，深浅主题角色色，全部内置 pop window 及 Mod palette/help 的共享折线标签框，Switch 列表/预览的外框接缝与真实键位字母高亮；Kitty Shift 独立事件不会吞掉 Leader，不存在窗口的切换错误不会退出前端。
- **窗格历史**：Tmux copy-mode 回滚、键盘选区、底端统一内容搜索栏及当前窗格历史搜索/匹配定位、复制到 Tmux buffer 与粘贴；应用未启用鼠标跟踪或 Mouse passthrough 关闭时鼠标滚轮回滚。系统剪贴板同步与终端鼠标拖选尚未实现。
- **命令助手**：直接复用 terminal_agent 后端、历史控制和原生 Bash Readline 接口；Cosmos 绘制覆盖行、紧凑按钮与被动 powerline，支持生成、取消、历史、回到 Bash 编辑执行。验证不代表真实模型端到端行为已全面验收。
- **图片/PDF 阅读基础**：常见位图与 PDF 渲染、Kitty 图形输出及字符降级，缩放、平移、翻页；图片底部缩略图、PDF 左侧缩略图及折叠，PDF 全文短语匹配、跨页高亮定位、页码跳转和内嵌大纲导航。查看状态可随会话重连恢复。
- **输入法与键盘预览**：真实 librime/rime_ice 接入，客户端共用开关与全半角、逐窗格组字、光标附近两行候选、无回车提交及右端状态指示；帮助和键位设置按空间显示紧凑键盘并高亮。详情及分发限制见 docs/input-method.md。
- **模块结构**：App 仅组装与事件委派；core/runtime/terminal/input/render/ui 分层，业务按 features 组织，助手与阅读器拥有各自状态。拆分前 app.py 保存在 references/app-before-split-2026-10-22.py。
- **渲染和诊断**：图形与字符共用输出批次，硬件光标状态同步，宿主无关的紧凑控件绘制接口；DEBUG/INFO/WARNING/ERROR 分级与有上限的 UI 日志。

## 部分完成，仍需补齐

- **完整 Agent**：已能分屏启动 OpenCode；尚未提供本服务所有 session/window/pane 的统一工具、按需读输出、会话操作权限链与任务管理。不能称为全局 Agent 已完成。
- **PDF 文本交互**：全文搜索与前后匹配已实现；文本选择与复制按设计暂留接口，不做 OCR。
- **缓存与预加载**：按字节预算的分池 LRU、前后页后台预读、缩略图非阻塞填充与清理后的过时代数保护已实现；持久磁盘缓存及大型真实文档性能验收仍待完成。
- **七区 UI**：session/pop window、状态栏、通知、助手 cover/powerline 已使用；left panel 尚未接入，状态栏组件、通知动作及统一键位编辑已接入；跨 Mod 通用布局仲裁尚未完成。
- **分发**：已有构建/打包脚本，参考项目版本有 vendor 清单；当前新版 UI、原生 Bash 模块及外部 PDF 依赖还没有完成少依赖 Linux x86_64 构建包的最终验收。

## 其他待验收与后续 UI

- OpenCode 配色修复仍需完整的原生/宿主实际对照；真实模型命令助手尚未完成端到端验收。
- 键盘只读预览和随选择高亮已实现；鼠标选择按键/键位录制仍待后续。

## 尚未实现的主要首版功能

- Rime 自包含运行包、依赖/许可证清单及无系统 Rime 的干净主机验收；输入法接入与逐目标组字已实现。
- Yazi 能力整合与统一交互，专用文件窗口、可折叠左侧文件/预览面板。
- 跨本服务所有窗格的保留终端输出搜索和结果定位。
- 全局 Agent 的 Cosmos 工具桥和 OpenCode 权限确认链。
- EPUB、Markdown 阅读模块。SVG/EPS/ICO 以及 OCR 不属于当前首版必须交付范围。

## 验证边界

验证按变更模块执行，不以过期的累计测试数代表当前覆盖。真实 PTY 综合回归覆盖终端、键鼠焦点、大小调整、Shift 扩展键序列、原生助手、图片/PDF、重连与终端模式恢复；本地 Kitty 验证了物理 Shift 按键、分屏线及局部高亮。助手重复切换回归曾完成 12 次，提示符和草稿各保留一份。

真实 Rime 与命令助手候选提交已有定向测试；这些结果不代表 Yazi、全局 Agent、付费模型、所有终端或真实 SSH 组合已经验收。旧 Rust 路径通过的功能也不能自动计入新版 UI。
