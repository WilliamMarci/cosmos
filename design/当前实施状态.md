# Cosmos 当前实施状态

更新日期：2026-10-22。本页描述当前代码状态；历史过程见《实施进度》，目标范围见《实施方案-v0.1》和《UI分区与Agent接入》。不把接口声明、示例或启动外部程序等同于完整功能交付。

## 当前定位

基础框架与终端工作区已经可运行，正在完成各业务模块接入，尚未达到设计中的完整首版。没有统一工时估算或验收权重，暂不报告容易误导的完成百分比。

当前主要开发入口为 `dev/cosmos-textual`，使用 Python + Textual 宿主和 Cosmos 自绘接口，终端会话与 VT 解析依赖隔离的 Tmux 服务。Rust 提供协调服务、RPC 和已有兼容前端；直接运行 `target/release/cosmos` 仍会进入旧 Rust 工作区，不等于新版 Python UI。尚未合并这两个启动入口。

## 已有运行验收

- **基础服务**：本机 IPC、版本协商、配置持久化、事件订阅与回放、通知服务；可信外部 Mod 的注册、启动、停止、就绪握手与进程管理。能力声明不构成系统沙箱。
- **终端工作区**：持续会话与重连，窗口/窗格创建和切换，分屏、缩放与调整大小，鼠标点击焦点；Tmux 几何分割线、交点和双窗格局部焦点高亮；精简当前窗口状态栏。
- **交互基础**：Leader 命令入口及上下文帮助，设置子菜单，深浅主题角色色，左右布局的 Switch 列表/预览与 btop 风格框；Kitty Shift 独立事件不会吞掉 Leader，不存在窗口的切换错误不会退出前端。
- **命令助手**：直接复用 terminal_agent 后端、历史控制和原生 Bash Readline 接口；Cosmos 绘制覆盖行、紧凑按钮与被动 powerline，支持生成、取消、历史、回到 Bash 编辑执行。验证不代表真实模型端到端行为已全面验收。
- **图片/PDF 阅读基础**：常见位图与 PDF 渲染、Kitty 图形输出及字符降级，缩放、平移、翻页；图片底部缩略图、PDF 左侧缩略图及折叠，PDF 当前页文字匹配高亮。查看状态可随会话重连恢复。
- **渲染和诊断**：图形与字符共用输出批次，硬件光标状态同步，宿主无关的紧凑控件绘制接口；DEBUG/INFO/WARNING/ERROR 分级与有上限的 UI 日志。

## 部分完成，仍需补齐

- **完整 Agent**：已能分屏启动 OpenCode；尚未提供本服务所有 session/window/pane 的统一工具、按需读输出、会话操作权限链与任务管理。不能称为全局 Agent 已完成。
- **PDF 搜索**：当前页词级子串高亮已实现；整份文档搜索、上一/下一匹配、跨页定位尚未形成完整交互。文本选择与复制按设计暂留接口，不做 OCR。
- **缓存与预加载**：已有小型内存缓存、独立缩略图缓存和过时渲染结果丢弃；统一字节预算、持久磁盘缓存、前后页后台预加载及取消调度尚未完整接入新版前端。
- **七区 UI**：session/pop window、状态栏、通知、助手 cover/powerline 已使用；left panel 尚未接入，跨 Mod 通用布局仲裁、可注册状态栏组件与统一键位编辑还不完整。
- **分发**：已有构建/打包脚本，参考项目版本有 vendor 清单；当前新版 UI、原生 Bash 模块及外部 PDF 依赖还没有完成少依赖 Linux x86_64 构建包的最终验收。

## 尚未实现的主要首版功能

- librime 输入法、rime_ice 配置接入、光标附近预编辑与候选、逐窗格组字及断线清理。
- Yazi 能力整合与统一交互，专用文件窗口、可折叠左侧文件/预览面板。
- 跨本服务所有窗格的保留终端输出搜索和结果定位。
- 全局 Agent 的 Cosmos 工具桥和 OpenCode 权限确认链。
- EPUB、Markdown 阅读模块。SVG/EPS/ICO 以及 OCR 不属于当前首版必须交付范围。

## 验证边界

最近一次 UI 单测为 25 项通过。真实 PTY 综合回归覆盖终端、键鼠焦点、大小调整、Shift 扩展键序列、原生助手、图片/PDF、重连与终端模式恢复；本地 Kitty 验证了物理 Shift 按键、分屏线及局部高亮。助手重复切换回归曾完成 12 次，提示符和草稿各保留一份。

这些结果不代表 IME、Yazi、全局 Agent、付费模型、所有终端或真实 SSH 组合已经验收。旧 Rust 路径通过的功能也不能自动计入新版 UI。

## Git 基线

根目录已建立统一 Git 仓库，terminal_agent 源码纳入同一仓库。原先没有正式提交的嵌套仓库元数据保存在 `.git/legacy-terminal-agent/`。当前基线分支为 `codex/baseline`；提交包含源码、设计、测试、依赖锁与 vendor 版本清单，排除克隆源码、编译产物、日志和运行状态。未配置远程仓库。工作流程见 `docs/development.md`。
