- 通知持久历史、过期显示、客户端独立关闭、服务级认领/释放/完成；不自动执行外部副作用。

- 基础构建包附带示例、SDK、接口说明、依赖许可证、运行库清单及校验值。

## 明确边界

- 当前稳定终端引擎仍用系统 Tmux；Cosmos 已自行承担默认客户端画面与输入，不需要定制 Tmux 源码补丁。
- 默认工作区由 Cosmos 直接绘制面板及全局通知；Tmux popup 只保留在显式 native 回退。
- 自有字符表面已与真实终端 grid 接通；图像、扩展终端协议和业务查看器仍未完成。
- 侧栏与共享 PTY 尺寸协调未完成，输入法、图像/PDF、Yazi、全局输出搜索和完整 Agent 尚未接入。
- 当前模组 action 启动受管理进程；向运行实例分发高级操作、完整键位编辑与 Mod 设置 schema 后续接入。
- 通知的互斥认领不保证外部副作用恰好执行一次；崩溃遗留的认领需恢复或释放。
- 正常关闭可清理 Mod 进程组，SIGKILL、主机崩溃或主动脱离进程组的可信程序不在此保证内。
- 构建包仍依赖系统 Tmux 与运行库，未达到最终低依赖可移植发行要求。
