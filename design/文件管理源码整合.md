# 文件管理：Yazi 源码整合

2026-10-24。按用户澄清：复制可复用的 Yazi 源码作为 Cosmos 文件管理实现，不启动系统 Yazi，也不把一个换配置的 Yazi 进程包装成整合。

## 已推进

- 从既有锁定 vendor/yazi 提取自然排序原源码与许可证，薄 ABI 供 Python 文件模型调用。来源与边界见 native/files/ORIGIN.md。
- 主机本地目录快照、目录优先及自然/大小/时间排序、隐藏项与筛选。
- Cosmos 自绘全窗格文件界面，统一调色板、键位设置、帮助、上下文 Actions、鼠标与通知路径。
- open 目录进入文件视图；支持文件进入共享 Reader，关闭阅读回原文件列表。后端 Shell 与工作目录不被改变。

## 仍需按原设计推进

- 复制/移动/重命名/回收站/删除、批量选择、冲突处理和任务生命周期：先明确可抽取的上游执行模块与对应依赖，再建立能力等价清单；不以 Python 包装器冒充已复用整个 Yazi 引擎。
- 左侧 dock 共用模型：顶部目录、上部列表、下部选中预览；无选择不预览。必须记录目标工作窗格，面板焦点不能改变关联对象。不能自动分屏冒充侧栏。
- 接入图片/PDF/富文本预览和明确打开对象语义，复用现有 Reader/缓存。
- 目录跟随复用可靠 Shell 目录报告；无法确认时保持最后目录并明确来源；不隐式 cd Shell。
- 补齐归档、搜索、外部工具、插件/VFS 等选定上游能力清单、依赖与缺失处理，然后逐项验收。

当前选用自然排序模块能以现有工具链单独编译；尚未据此选定全部 Yazi 引擎版本或宣布上游 26.9.1 可整体构建。代码及文档保持这一边界。
