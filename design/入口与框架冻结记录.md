# 入口与框架冻结记录

2026-10-22，按用户确认冻结入口与技术边界，不代表首版业务功能全部完成。

- 唯一 UI：根目录 `./cosmos [SESSION] [--debug]`，执行 Python `cosmos_tui.__main__`。
- `dev/cosmos-textual` 仅转到根入口；Rust 二进制无参数及 attach/workspace 也转到该入口。
- Python + Textual 宿主、Cosmos 自绘组件承担 UI；特殊覆盖行和未来 IME 使用自绘接口。
- Tmux 负责持续终端会话及 VT 解析，使用独立 socket。
- Rust 暂留协调服务、Mod 进程生命周期、RPC、持久配置、事件及通知。未来是否迁移另行决定；本次不迁移服务、不破坏既有会话。
- 旧 Rust 工作区、面板及独立查看器 UI 入口停用；源码保留历史参考，不继续发展两套 UI。
- 退出 UI 后，终端恢复完成才显示 ANSI Logo。detach 表示主动分离；exit 表示客户端退出或会话结束。会话是否保留单独查询；只有确认保留才给重连命令。
- Logo 编辑源为 `design/cosmos-logo.ansi`，运行资源为 `python/cosmos_tui/assets/cosmos-logo.ansi`；修改时同步，包内包含运行资源。
- 浮岛铺满源窗格；状态点左侧一格，状态与请求间一格，编辑区直接连接操作簇。hover/focus 颜色立即切换。

正式接口只在 docs 中维护当前行为；新增功能设计、迁移计划及尚未实现能力保留在 design。后续在这套框架上补 IME、Yazi、搜索、全局 Agent 等功能，未经确认不再切换技术路线。
