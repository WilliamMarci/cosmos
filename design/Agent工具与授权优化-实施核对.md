# Agent 工具与授权优化：实施核对

日期：2026-11-01。对应此前工具调用绕路与权限粒度分析。
正式接口以 `docs/agent*.md` 为准；本文记录实施范围和剩余计划。

## 本阶段已完成

- 稳定目标解析：`1:4` 明确表示 `$1` / `%4`，列表提供 display_id。
- 正式 open_file：Reader/Files 路由、实际目标与 pending 加载回执，禁止未知格式擅自打开桌面程序。
- 终端任务组合授权：绑定原生 Agent 对话、任务与 pane；一次接管确认覆盖普通受控输入和自己的释放。不会保存成项目全局授权。
- 原生权限适配：对话身份由运行时签名注入，MCP 内按对话分离快照与令牌；保留显式拒绝。人工暂停后旧令牌无效，恢复必须重新观察、申请和确认。
- terminal_step：单次单行粘贴、显式提交、返回观察；分步骤撤销检查和部分投递回执。
- 新建终端/Session：直接返回稳定 ID、实际 cwd、进程状态和精简快照。省去 pwd 与多次额外屏幕读取；不谎称 shell 已完成初始化。
- 轻量客户端/当前上下文查询、Actions scope/分类筛选、focus 直接返回上下文。
- 内置技能与默认系统 prompt 已改为观察、接管、有界操作、暂停优先路径，不再指导旧的源码探索或分离输入/Enter 流程。

## 后续补齐（同日）

- 新增 read_history：读取屏幕以外的 Tmux 保留输出，按快照分页和文字筛选，避免重复抓取大段历史。四个限时快照，受私密 pane 限制。

- 工作区管理已补齐独立组合授权：acquire_workspace / release_workspace，创建、重命名、焦点切换使用 workspace_token；与终端控制授权完全分开。
- Reader 已按请求 ID 接入内部生命周期事件，reader_events 返回实际 loaded / failed / superseded，错误继续走统一通知；不依靠终端截图判断。
- 系统 OpenCode 的回退已改成直接打开；没有 Cosmos 工具、技能、主题、配置或凭据注入。

## 仍未完成

- 状态查询返回活动 pane 和 UI context；尚未提供 Reader/Files 的内容语义观察。
- 自动模型唤醒/取消正在运行的模型请求、持久任务调度、周期任务、Tasks 总览、重启后任务恢复，仍遵循观察接管与调度设计中的后续阶段。
- 控制任务孤儿记录没有自动过期；重启 Agent 不恢复旧授权，用户通过现有 End/Resume Actions 恢复。

## 验证边界

验证使用隔离 Tmux/Vim、测试 UI/socket、原生 OpenCode 权限服务与数据库、真实 MCP 工具注册执行路径；不调用付费模型、不操作用户现有会话、不构建发行包。正式文档说明进程已运行不等于 shell 已就绪，投递成功不等于任务已完成。


上述 Workspace / Reader / history 已更新到 docs，并补充实际 Reader 成功/失败、历史分页和原生权限用例。自动模型唤醒、持久调度、任务面板仍未实现；当前新增的 Reader 内部事件不会自动触发模型，不能将其视为已完成调度阶段。
