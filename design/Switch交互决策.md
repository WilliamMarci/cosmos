# Switch 交互决策

2026-10-25，按用户选项确认：

- Session → Window → Pane 可折叠树，右侧继续显示真实窗格布局预览。
- 仅选中或悬停行显示切换、重命名、更多三个紧凑控件，沿用 Cosmos 色块与 Unicode 字符。
- 底部固定新建 Session，名称必填，目录继承当前工作目录。
- 沿用 Tmux 的稳定 session/window/pane ID，与显示编号分开；补齐按 ID 定位和窗格编号选择。

当前可用行为维护在 docs/switch.md。后续可以再讨论关闭/删除确认、窗格移动、窗口跨会话迁移、收藏与排序，不在本轮默认加入破坏性动作。
